# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.


# Описание проекта
Проект представляет собой веб-сервер для управления задачами. Пользователь может:
- Добавлять задачи с названием, комментарием, датой и правилом повторения
- Смотреть список текущих задач
- Редактировать существующие задачи
- Отмечать задачи выполненные
- Удалять задачи
